КАК ЗАПУСТИТЬ ВИКТОРИНУ

1. Открой index.html в браузере — сама веб-версия уже готова.
2. Папка images должна содержать картинки из твоей исходной программы.
3. Имена файлов картинок менять не нужно: код автоматически использует имена из твоих путей.

ВАЖНО:
Сейчас в исходном сообщении была только программа викторины, а сами картинки отдельно не были загружены.
Поэтому в архиве есть пустая папка images. Перед публикацией сайта положи туда все картинки из:
 /Users/dasha/программы/images/
